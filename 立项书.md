| **一、技术路线**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 本项目以“财政压力→政府产业引导基金运作→地方创新绩效”为核心研究链条，遵循“理论分析—数据整理—实证识别—机制展开—异质性比较—稳健性检验”的总体思路展开研究。技术路线并非简单罗列计量方法，而是按照“先厘清理论逻辑、再识别总体效应、继而揭示作用渠道、最后检验结论边界”的顺序逐步推进，以保证研究设计与结论解释彼此衔接、层层递进。 |
| **阶段一：理论梳理、数据整合与面板构建。** 首先系统梳理财政压力、政府产业引导基金与地方创新绩效的相关研究，在此基础上明确核心变量之间的理论关系和研究假说，为后续实证分析提供统一的分析框架。随后整合CNRDS中国创新专利研究数据库、CEIC宏观财政数据库、清科PEdata与投中CVSource引导基金投资数据、樊纲省级市场化指数以及市级财政透明度数据，构建城市—年份层面的非平衡面板。之所以采用面板数据而不是单一时点的截面数据，是因为本研究既关注不同城市之间的结构差异，也关注同一城市在不同时期财政压力、基金运作和创新绩效的动态变化；只有同时保留地区维度与时间维度的信息，才能较为完整地刻画财政压力的持续影响及其阶段性表现。 |
| **阶段二：基准回归检验总体效应。** 在完成变量构造和描述性统计后，基准回归将以地方创新绩效为被解释变量，以滞后一期财政缺口率和债务率为核心解释变量，采用双向固定效应模型识别财政压力的总体影响。之所以将双向固定效应模型作为基准模型，是因为不同城市在产业基础、行政资源、创新传统和区位条件等方面存在大量难以直接观测但相对稳定的差异，若不加控制，容易将这些长期不变因素误判为财政压力的作用；与此同时，不同年份还会共同受到宏观政策、经济周期和制度环境变化的影响，因此还必须控制年份固定效应。通过同时吸收城市固定效应和年份固定效应，可以更大程度上剥离“城市固有差异”和“年份共同冲击”的干扰，使财政压力系数更接近其净效应。 |
| **阶段三：机制检验揭示传导路径。** 在确认总体效应之后，项目将重点考察财政压力是否通过扭曲政府风险偏好、弱化“投早投小”导向、压缩投资额度与投资笔数等渠道影响地方创新绩效。机制检验采用两步法，并以交互项回归作为辅助说明。之所以采用两步法，是因为机制变量本身往往与创新绩效存在较强的内生联系，若直接将其与核心解释变量一并纳入结果方程，容易出现“坏控制”问题，从而削弱机制识别的可信度。两步法先检验财政压力是否显著影响机制变量，再结合基准回归结果和理论逻辑解释其传导过程，更适合本项目当前的数据基础与识别目标。对于暂时难以直接量化的“挤出市场化VC”和“弱化耐心资本属性”等机制，则以理论论证和间接证据作为补充，并为后续数据拓展预留空间。 |
| **阶段四：内生性处理强化因果识别。** 考虑到财政压力与地方创新绩效之间可能存在反向因果和遗漏变量偏误，本项目在内生性处理上将以工具变量法为主，同时仍计划采用多种方法进行交叉验证。之所以重点采用工具变量法，是因为创新基础较强的城市往往财政收入更稳、融资能力更强，普通固定效应回归仍然难以完全排除“创新反过来影响财政状况”的可能；而工具变量法能够利用外生变动提取财政压力中不受地方创新直接影响的部分，从而提升因果识别的可信度。具体而言，项目拟以同省其他城市平均财政缺口率等外生冲击为工具变量开展2SLS估计，并报告弱工具变量检验和过度识别检验结果。同时，考虑到单一识别策略也存在局限，项目仍计划辅以动态面板估计、政策冲击识别和安慰剂检验等多种方法，形成相互印证的识别框架，以增强研究结论的说服力。 |
| **阶段五：异质性检验、稳健性检验与结论提炼。** 在总体效应和作用机制得到识别后，项目将通过分组回归开展异质性检验，重点比较不同地区、不同城市行政等级、不同市场化水平、不同财政透明度和不同产业结构下财政压力影响地方创新绩效的差异。之所以采用分组回归，是因为财政压力的影响并不会在所有城市中完全一致，不同制度环境、资源禀赋和基金运作条件会改变其作用强度与表现形式，只有通过分组比较，才能识别哪些城市更容易受到冲击、哪些条件能够发挥缓冲作用。与此同时，项目还将通过替换核心变量、调整样本区间、改变模型设定、排除极端样本等方式开展稳健性检验，以避免结论过度依赖某一特定口径或某一种估计方式。在上述分析基础上，最终提炼具有针对性的政策建议，为优化政府产业引导基金运作机制、缓解财政压力对地方创新的不利影响提供经验证据。 |

| **三、尚缺少的条件及解决方法**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **（1）部分城市债务数据缺失较严重。** 地方政府债务余额数据仅覆盖2014年以后且存在约42.6%的缺失（v2面板中ln(债务率)仅有1,669个有效观测值，覆盖257个城市），导致以ln(债务率)为核心解释变量的子样本检验力受限。**解决方法：** 以财政缺口率（覆盖2,907个观测值、291个城市）为主回归指标，ln(债务率)作为辅助验证；同时尝试补充省级债务数据进行分摊估算，并在论文中客观报告两套指标的结果差异与样本量限制。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **（2）市场化VC投资数据缺乏。** H3假说（财政压力挤出市场化风险投资）因缺少各城市-年份的市场化VC/PE投资总额与活跃度数据而无法直接检验。当前数据仅覆盖政府引导基金的投资事件，不含市场化机构的独立投资。**解决方法：** 在论文中进行充分的理论论证并明确标注数据局限，通过异质性分析（在市场化程度高的地区财政压力对创新的抑制效应应更强，因为有更多VC可被挤出）提供间接证据，同时提出后续路径——通过清科私募通获取城市级VC投资总额与笔数，或通过中基协数据获取各地区私募股权基金备案数，或构建"引导基金撬动社会资本的杠杆率"代理变量。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **（3）引导基金退出数据缺乏。** H4假说（财政压力弱化耐心资本属性）因缺乏退出/清算事件数据而难以直接度量投资持有周期。当前投资事件数据有投资时间但无退出时间，无法计算持有周期。**解决方法：** 以广义早期投资占比（种子+初创+扩张期投资次数/总次数）作为间接代理变量——越多投资进入早期阶段隐含更长的退出周期，更具耐心资本属性。在论文中明确说明限制并提出后续数据补充方向：获取引导基金退出/清算事件数据以计算平均持有周期，或获取基金章程中的存续期限信息构建"存续期限/剩余存续比"指标。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **（4）财政缺口率系数方向待进一步确认。** 两轮初步回归中财政缺口率对ln(发明专利)的估计系数均为正（v2核心控制下β=1.078, p=0.026；v1无控制下β=0.177, 不显著），与理论预期的负向影响不一致，可能反映反向因果偏误（财政缺口大的城市恰好是经济活跃、创新产出高的城市）或遗漏变量干扰。**解决方法：** 在正式分析中通过工具变量法（Bartik IV的2SLS）修正内生性偏误，观察IV估计量是否修正为负向效应；同时检验v1/v2中被解释变量为发明申请量（而非授权量）时是否出现系数方向差异（申请量更易受策略性申请驱动），并在论文讨论部分对可能的解释（如反向因果、OLS偏误方向）进行详细辨析。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
