# 面板数据变量数据源说明

本文档用于记录当前地级市总面板中各类变量的**一级数据源**、**二级数据源**和**当前进入面板的整理文件**，便于后续换对话、换人或补充数据时快速接续。

说明：

- **一级数据源**：最原始、最上游的数据来源文件
- **二级数据源**：在一级数据源基础上经过清洗、汇总、聚合后形成的中间文件
- **当前面板文件**：最终并入 `地级市总面板_编制版.csv`、`地级市总面板_2015_2024版.csv` 和英文版面板的文件

## 14. 后续补数据原则

如果以后继续补：

- 专利受理量
- 其他机制变量
- 新的异质性变量

建议统一流程：

1. 先确认城市层级和年份格式
2. 先形成干净的二级数据源
3. 再并入中文主面板
4. 最后从中文主面板重导一份英文回归版
