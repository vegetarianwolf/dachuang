# 回归面板使用说明

## 默认回归面板

以后在使用 `reg` 技能或编写 Stata 回归脚本时，默认优先使用这份英文变量名面板：

- [地级市总面板_2015_2024_英文版.csv](C:/Users/Joe，/OneDrive/Desktop/dachuang/dachuang/面板数据/地级市总面板_2015_2024_英文版.csv)

## 原因

- Stata 在当前环境下对中文变量名和中文路径兼容性不稳定。
- 英文变量名面板可以稳定生成 `.do`、`.log` 和结果表。
- 中文主面板仍保留，用于人工查看和核对变量含义。

## 文件分工

- 中文总面板：
  - `地级市总面板_编制版.csv`
  - `地级市总面板_2015_2024版.csv`
  - 用于人工检查、变量核对

- 英文回归面板：
  - `地级市总面板_2015_2024_英文版.csv`
  - 用于 Stata 回归与 `reg` 技能默认输入数据

## 约定

除非用户明确要求使用中文变量名面板，否则后续所有回归默认：

1. 使用 `地级市总面板_2015_2024_英文版.csv`
2. 优先输出英文变量名 `.do` 文件
3. 同步输出 `.log`、结果表和 `实证结果` Markdown 说明文档
