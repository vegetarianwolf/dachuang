# 财政债务约束下政府产业引导基金扶持创新效果研究：可执行实证方案

## 一、研究问题与总体识别思路

本文拟研究地级市层面政府产业引导基金对城市创新的促进作用，并进一步考察财政债务压力如何影响这一政策效果，以及其作用机制是否主要通过改变基金投资风险偏好和耐心资本属性实现。

建议将研究主线明确表述为：

- 政府产业引导基金能否促进地级市创新产出。
- 财政债务压力是否削弱政府产业引导基金的创新扶持效果。
- 财政债务压力是否通过改变基金投资风险偏好与投资周期，进而影响基金的创新促进作用。

从计量识别上，建议采用地级市面板数据的双向固定效应模型，以城市固定效应控制不随时间变化的城市特征，以年份固定效应控制全国层面的共同冲击。若后续担心省级宏观政策和财政制度差异干扰，也可以进一步加入省份乘年份固定效应。

## 二、样本与面板结构

- 研究单元：地级市-年份。
- 样本区间：以基金设立数据、基金投资事件数据、地级市债务财政数据和专利数据共同重叠年份为准。
- 按现有原始数据结构，实际样本期大概率适合设定为 2015-2023 年，最终以数据清洗后的完整性检验结果为准。

建议优先保留普通地级市样本；直辖市、副省级城市是否保留，可以在基准回归中保留，在稳健性检验中剔除。

## 三、核心变量构造方案

### 1. 被解释变量：城市创新产出

建议使用专利申请受理数衡量城市创新表现，并统一做对数化处理：

- 基准指标：`ln(1 + 专利申请受理总数)`
- 更优指标：`ln(1 + 发明专利申请受理数)`
- 扩展指标：实用新型申请受理数、外观设计申请受理数

从理论上看，引导基金对高质量创新的影响更应体现在发明专利上，因此建议将发明专利作为主回归口径，总量专利作为补充。

同时建议考虑创新产出的滞后性：

- 主回归可使用 `t+1` 年或 `t+2` 年专利作为被解释变量；
- 或对基金变量使用滞后一期、两期形式。

### 2. 核心解释变量：地级市政府产业引导基金规模

根据现有基金设立数据库，地级市层面已可识别以下信息：

- 基金级别
- 注册地区
- 成立时间
- 目标规模
- 基金分类

建议至少构造三类基金变量：

- 当年新设基金规模流量：城市在当年新成立的地市级引导基金目标规模之和
- 基金累计规模存量：截至当年已成立基金的累计目标规模
- 基金数量：当年新设基金数量或累计基金数量

在基准回归中，更推荐使用滞后一期的累计基金规模存量，原因是创新对政策资本供给的响应往往并非当期即时实现。

建议处理方式：

- 规模变量统一转为亿元或百万元口径
- 必要时按价格指数平减为不变价
- 采用 `ln(1 + x)` 形式进入回归

### 3. 调节变量：财政债务压力

财政债务压力是本文的重要调节因素。建议以地级市债务余额和地方财政能力的相对关系衡量，而不是只用债务绝对规模。

推荐基准口径：

- `债务余额 / 一般公共预算收入`

推荐替代口径：

- `债务余额 / 一般公共预算支出`
- `债务余额 / GDP`
- `一般债务余额 / 一般公共预算收入`
- `专项债务余额 / 一般公共预算收入`

这类比值越高，表明地方财政约束越强，政府在使用产业引导基金时越可能表现出更强的短期化和保守化倾向。

## 四、机制变量的可执行构造

你们提出的两个“中介”本质上应理解为财政债务压力影响基金创新效果的作用渠道。建议在论文中表述为“机制变量”或“中介化调节机制”。

### 1. 机制一：基金投资风险偏好

该机制可基于基金投资事件数据库中的 `投资阶段` 字段进行城市年度聚合。

建议构造以下指标：

- 早期项目投资占比：种子期、初创期、A 轮前项目占该市引导基金全部投资事件的比例
- 高风险投资事件占比：按事件数量统计的早期投资比例
- 早期项目投资金额占比：若金额缺失较少可使用，否则不作为主指标

理论预期：

- 财政债务压力越高，地方政府越可能压低基金容错空间；
- 因而引导基金越倾向于配置到成熟期、扩张期、较低风险项目；
- 表现为风险偏好下降。

### 2. 机制二：基金投资周期与耐心资本属性

若现有基金信息表中可提取基金期限、退出期限或存续年限，则可直接构造：

- 城市年度基金平均存续期限
- 城市年度基金平均退出期限

若这类字段缺失，则可利用基金设立表与投资事件表匹配，构造行为型指标：

- 基金成立至首次投资的平均时长
- 基金成立至各笔投资发生的平均间隔
- 成立满 3 年后仍持续投资的事件占比
- 成立满 5 年后仍持续投资的事件占比

理论预期：

- 财政债务压力越高，地方越可能要求基金尽快出效应、快形成政绩；
- 因而基金投资周期缩短，耐心资本属性减弱；
- 这会降低其对创新项目，尤其是高不确定性技术创新项目的支持能力。

## 五、基准模型与扩展模型

### 1. 基准回归

建议基准模型为：

`Innovation_it = beta * Fund_i,t-1 + gamma * X_it + city FE + year FE + error_it`

其中：

- `Innovation_it` 为城市创新产出
- `Fund_i,t-1` 为滞后一期基金累计规模或基金流量
- `X_it` 为控制变量

### 2. 调节效应模型

为检验财政债务压力是否削弱引导基金作用，建议估计：

`Innovation_it = beta1 * Fund_i,t-1 + beta2 * Debt_it + beta3 * Fund_i,t-1 * Debt_it + gamma * X_it + FE + error_it`

若交互项系数显著为负，可解释为：

- 债务压力越大，引导基金对创新的边际促进作用越弱。

### 3. 机制检验模型

第一步先检验债务压力是否影响机制变量：

`Risk_it = a1 * Debt_it + a2 * Fund_i,t-1 + gamma * X_it + FE + u_it`

`Patience_it = c1 * Debt_it + c2 * Fund_i,t-1 + gamma * X_it + FE + v_it`

第二步再检验机制变量是否改变基金创新效应：

`Innovation_it = beta1 * Fund_i,t-1 + beta2 * Debt_it + beta3 * Fund_i,t-1 * Debt_it + beta4 * Fund_i,t-1 * Risk_it + beta5 * Fund_i,t-1 * Patience_it + gamma * X_it + FE + error_it`

若加入机制交互项后，`Fund * Debt` 的系数绝对值下降，则可以说明财政债务压力部分通过改变基金行为方式影响其创新扶持效果。

## 六、控制变量建议

结合现有 `市级数据` 文件夹，建议使用以下控制变量：

- 经济发展水平：人均 GDP 或总 GDP
- 城市规模：常住人口
- 产业结构：第二产业增加值占 GDP 比重
- 开放程度：实际利用外资占 GDP 比重
- 金融发展：贷款余额占 GDP 比重
- 财政科技支持：科学支出占一般公共预算支出比重
- 制度环境：市场化指数、财政透明度

处理建议：

- 连续变量尽量做对数化或比值化
- 对极端值进行 1% 或 0.5% 缩尾处理
- 标准误至少按城市层面聚类

## 七、现有市级数据支持的高价值异质性分析

扫描 `原始数据打包_20260401/市级数据` 后，现有数据最适合开展的异质性分析并不是简单的区域分组，而是围绕“什么样的城市更能把引导基金转化为创新产出”来做。

### 1. 财政自给能力异质性

推荐指标：

- `一般公共预算收入 / 一般公共预算支出`

数据来源：

- `地级市财政收入.csv`
- `地级市财政支出.csv`

理论含义：

- 财政自给率高的城市，预算自主性更强，对债务压力的缓冲能力更高；
- 此类城市更可能维持长期创新扶持和基金容错空间；
- 因而引导基金促进创新的效果可能更强。

### 2. 债务结构异质性

推荐指标：

- `专项债务余额 / 总债务余额`
- `一般债务余额 / 总债务余额`

数据来源：

- `地方政府债务：地级市：余额.csv`

理论含义：

- 不同债务结构反映地方财政支出责任、项目融资方式和预算压力来源不同；
- 债务结构可能影响地方政府对引导基金的政策目标设定；
- 在一般债压力更强时，地方可能更偏好短周期、低风险投资。

### 3. 科技财政倾向异质性

推荐指标：

- `科学支出 / 一般公共预算支出`

数据来源：

- `财政支出：科学：地级市.csv`
- `地级市财政支出.csv`

理论含义：

- 科技支出占比高的城市，往往本身就更重视创新治理；
- 这类城市中，引导基金更可能与财政科技支出形成互补，而非替代；
- 因而创新促进作用可能更显著。

### 4. 市场化水平异质性

推荐指标：

- 市场化总指数
- 政府与市场关系
- 要素市场发育程度
- 市场中介组织与法律制度环境

数据来源：

- `1997-2024年市场化指数和各分项指数 的副本.csv`

理论含义：

- 市场化程度越高，政府产业引导基金越可能按市场化逻辑运作；
- 基金筛选、投后管理和退出机制也更成熟；
- 因而基金更有可能真正发挥“引导”而不是“行政配置”功能。

说明：

- 该指标目前为省级面板，可按省份匹配到地级市使用。

### 5. 金融发展水平异质性

推荐指标：

- `贷款余额 / GDP`
- 若清洗后可行，可进一步构造 `中长期贷款占比`

数据来源：

- `金融机构贷款余额.csv`
- `地级市总GDP.csv`

理论含义：

- 在金融供给不足的城市，引导基金可能更像融资替代工具；
- 在金融发展较好的城市，引导基金更可能发挥资本撬动和信号认证作用；
- 因此两类地区中政策效果的形成机制可能不同。

### 6. 开放程度异质性

推荐指标：

- `实际利用外资 / GDP`

数据来源：

- `实际利用外资.csv`
- `地级市总GDP.csv`

理论含义：

- 开放程度较高的城市通常拥有更强的技术吸收和知识溢出能力；
- 引导基金进入后，更容易放大创新网络和资源配置效率；
- 因而对创新的促进作用可能更明显。

### 7. 产业结构异质性

推荐指标：

- `第二产业增加值 / GDP`

数据来源：

- `地级市第二产业.csv`
- `地级市总GDP.csv`

理论含义：

- 产业引导基金往往更容易在制造业基础较强、产业承接能力较好的城市落地；
- 若地方具有较强实体产业基础，基金支持更容易转化为专利和技术升级。

### 8. 财政透明度异质性

推荐指标：

- 市级财政透明度得分

数据来源：

- `市级政府财政透明度（2013-2024年） 的副本.csv`

理论含义：

- 财政透明度更高的城市，预算约束和政策执行更规范；
- 这有助于抑制短期政绩导向和资源错配；
- 从而提升引导基金支持创新的效率。

### 9. 经济发展水平与城市规模异质性

推荐指标：

- 人均 GDP
- 常住人口

数据来源：

- `地级市人均GDP.csv`
- `常住人口.csv`

理论含义：

- 高发展、高人口城市通常具备更完整的创新生态、人才基础和企业储备；
- 但这类分组相对常见，建议作为补充异质性，而非论文核心亮点。

## 八、异质性分析的优先排序建议

如果只选择 4 组最有理论价值、且最契合本文主线的异质性，我建议优先使用：

1. 财政自给能力
2. 债务结构
3. 科技财政倾向
4. 市场化水平

这四组最能回应“财政约束下，何种制度与财政条件决定引导基金能否真正支持创新”这一核心问题。

## 九、实证实施中的关键注意事项

### 1. 不要将基金注册地机械等同于实际受益地

基金注册在本地，不代表一定主要投向本地企业。建议在稳健性检验中补充使用：

- 本地引导基金投资本地企业的事件数量
- 本地引导基金投资本地企业的金额

### 2. 不要只使用基金目标规模

目标规模是最稳定、最容易清洗的主指标，但并不等于真实投放强度。建议在稳健性分析中加入：

- 基金数量
- 投资事件数量
- 本地被投企业数量

### 3. 注意创新的滞后效应

若用当期基金解释当期专利，结果即便显著也不一定有说服力。建议：

- 至少使用滞后一期基金变量
- 或直接用未来一期、两期专利指标

### 4. 机制检验不要写成过于简单的传统三步中介

你们的研究结构更适合写成：

- 债务压力改变基金行为方式；
- 基金行为方式进一步影响基金促进创新的能力。

因此更适合采用“调节效应 + 机制变量”的表达，而不是简单套用标准中介模板。

## 十、建议优先落地的主方案

建议尽快固定如下主回归方案：

- 被解释变量：`ln(1 + 发明专利申请受理数)`
- 核心解释变量：`滞后一期累计地市级引导基金规模`
- 调节变量：`债务余额 / 一般公共预算收入`
- 机制变量一：`早期投资占比`
- 机制变量二：`基金成立至投资的平均间隔` 或 `成立满3年后持续投资占比`
- 固定效应：城市固定效应、年份固定效应
- 控制变量：人均 GDP、人口、第二产业占比、FDI、贷款余额占比、科技支出占比、市场化指数、财政透明度

## 十一、下一步数据整理建议

后续可以按以下顺序推进：

1. 先将所有宽表城市数据转成长表，统一为 `city-year` 结构
2. 清洗基金设立数据库，识别地市级引导基金及其成立年份、注册地和规模
3. 清洗基金投资事件数据库，匹配基金名称并构造风险偏好和耐心资本指标
4. 清洗专利数据库，形成城市年度专利指标
5. 合并为最终地级市面板数据集
6. 依次开展基准回归、调节效应、机制检验和异质性分析
