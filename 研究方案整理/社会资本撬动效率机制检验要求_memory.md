# 社会资本撬动效率机制检验要求 memory

> 本文件用于后续对话继承，只整理今天跑回归前已经明确的研究要求和变量口径。
> 不记录、不继承 2026-05-18 后续已经被指出“模型用错了”的回归设定、回归结果或显著性结论。

## 1. 研究对象

围绕“社会资本撬动效率”开展机制检验，考察财政债务约束是否会削弱政府引导基金撬动社会资本的能力，以及社会资本撬动效率是否进一步促进城市创新产出。

机制链条应围绕：

```text
债务约束 -> 社会资本撬动效率/社会资本参与比例 -> 创新产出
```

## 2. 理论方向要求

后续机制检验必须优先服务于以下理论方向：

1. 机制方程中，债务变量系数预期为负。
   - 含义：债务压力越高，政府引导基金撬动社会资本的能力越弱。
   - 可考虑的债务变量包括 `debt_pressure`、`debt_pressure_l1`、`debt_burden`、`debt_burden_l1`，具体以数据口径和模型设定为准。

2. 结果方程中，社会资本撬动效率相关指标系数预期为正。
   - 含义：社会资本撬动效率越高，创新产出越高。
   - 结果方程中的关键解释变量应是撬动效率或社会资本参与比例，而不是债务变量本身。

3. 只有同时满足“机制方程债务变量负向”和“结果方程撬动效率变量正向”的结果，才可作为全链条符合理论方向的机制证据。

## 3. 变量口径要求

### 3.1 社会资本机制变量

本机制检验要求使用比例变量或效率变量，不使用绝对数量变量作为核心机制变量。

优先保留：

| 技术变量名 | 研究含义 | 使用建议 |
|---|---|---|
| `soccap_leverage` | 社会资本撬动效率，社会资本认缴额 / 政府认缴额 | 核心机制变量 |
| `soccap_share_total` | 社会资本认缴额占总认缴额比例 | 有意义的比例机制变量 |
| `gov_share_total` | 政府认缴额占总认缴额比例 | 可反向构造非政府资本占比 |
| `1 - gov_share_total` | 非政府资本认缴占比 | 可作为社会资本参与比例的替代口径 |

不作为核心机制变量：

| 技术变量名 | 原因 |
|---|---|
| `soccap_amt` | 绝对金额，不符合“用比例变量”要求 |
| `gov_amt` | 绝对金额 |
| `gp_amt` | 绝对金额 |
| `unknown_amt` | 绝对金额且经济含义不够清晰 |
| `fund_commit_total` | 绝对金额 |
| `matched_commit_amt` | 匹配额，属于匹配率相关口径 |
| `soccap_fund_count` | 绝对数量，不符合“用比例变量”要求 |

### 3.2 匹配率相关指标

后续整理和机制检验中应去掉匹配率相关指标，只保留经济含义明确的社会资本比例或撬动效率指标。

明确排除：

| 技术变量名 | 排除原因 |
|---|---|
| `matched_share_total` | 匹配率/数据匹配覆盖口径，不是社会资本撬动效率本身 |
| `matched_commit_amt` | 匹配额口径，不作为机制变量 |

### 3.3 变量名称展示

输出给用户阅读的 Markdown 结果文档中，变量应尽量改回原有中文含义或清晰中文名，不要只展示难懂的临时变量名。

建议展示方式：

| 技术变量名 | 结果文档建议名称 |
|---|---|
| `soccap_leverage` | 社会资本撬动效率 |
| `soccap_share_total` | 社会资本认缴占比 |
| `gov_share_total` | 政府认缴占比 |
| `1 - gov_share_total` | 非政府资本认缴占比 |
| `debt_pressure` | 债务压力 |
| `debt_pressure_l1` | 滞后一期债务压力 |
| `debt_burden` | 债务负担 |
| `debt_burden_l1` | 滞后一期债务负担 |

## 4. 不允许混淆的处理

1. 不要对基金规模取对数。
   - 包括 `fund_est_scale`、`fund_est_scale_cum`、`fund_est_scale_roll5` 等基金规模变量。

2. 不要对社会资本撬动效率取对数。
   - 包括 `soccap_leverage` 及其作为机制变量的主要变体。

3. 可以根据研究需要对创新产出变量采用合适口径，但不能把“基金规模不能取对数”和“撬动效率不能取对数”的要求混淆掉。

4. 不要把绝对基金数量或绝对认缴金额误当作“撬动效率”。

## 5. 可接受的样本与数据处理

在学术规范范围内，可以尝试不同样本处理以检验理论链条是否成立，但所有处理必须在结果文档中说明清楚。

可尝试的处理包括：

1. 对极端比例变量进行 winsorize 或合理截尾。
2. 对债务变量进行 winsorize 或合理截尾。
3. 使用滞后一期债务变量，以缓解同步性问题。
4. 排除明显异常年份或特殊冲击年份，并说明理由。
5. 使用基金活跃样本，例如存在基金设立、累计基金规模或滚动窗口基金活动的城市年份。
6. 使用平衡面板或保留主要城市样本作为稳健性尝试。
7. 对社会资本撬动效率的极端值进行合理处理，例如剔除政府认缴额过小导致的异常杠杆比。

这些处理的目的应是识别样本结构是否导致理论方向被掩盖，而不是不透明地挑选结果。

## 6. 后续模型设定提醒

1. 后续若继续跑机制检验，需要先确认“机制方程”和“结果方程”的具体模型形式。
2. 不要继承已经被指出错误的模型设定。
3. 如果使用中介机制框架，应至少区分：
   - 机制方程：社会资本撬动效率/社会资本参与比例作为被解释变量，债务变量作为核心解释变量。
   - 结果方程：创新产出作为被解释变量，社会资本撬动效率/社会资本参与比例作为关键解释变量。
4. 如果使用调节效应框架，需要明确交互项的理论含义，不能用交互项结果替代上述机制链条，除非用户另行确认。
5. 结果整理时应区分：
   - 全链条符合理论方向；
   - 仅机制方程符合；
   - 仅结果方程符合；
   - 方向不符合或经济含义弱。
