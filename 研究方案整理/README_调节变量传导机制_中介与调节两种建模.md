# 调节变量传导机制：机制变量作为中介或调节变量的两种建模方案

## 1. 问题背景

在本文的主回归设定中，核心关系可写为：

`引导基金扶持强度（X） -> 创新产出（Y）`

并进一步考虑财政债务压力 `N` 的调节作用：

`X × N -> Y`

也就是检验：财政债务压力是否会改变引导基金扶持创新的效果。

后续的机制检验，核心是在回答：

**债务压力为什么会对 `X -> Y` 的关系产生调节作用？**

围绕这一问题，机制变量 `M` 可能有两种不同角色：

- 作为基准回归中的**中介变量**
- 作为基准回归中的**调节变量**

两种角色对应的模型设定不同，不能混用。

---

## 2. 共同的基准调节模型

无论后续把 `M` 理解成中介还是调节变量，第一步都应先确认主回归中的调节效应存在。

基准调节模型：

`Y_it = beta0 + beta1 X_it + beta2 N_it + beta3 X_it * N_it + gamma Controls_it + FE + e_it`

其中：

- `X`：引导基金扶持强度或基金规模
- `Y`：创新产出
- `N`：财政债务压力
- `Controls`：控制变量
- `FE`：城市固定效应和年份固定效应

重点看 `beta3`：

- 若 `beta3` 显著，说明财政债务压力确实会调节引导基金扶持创新效果；
- 之后才有必要继续做“调节效应的传导机制检验”。

---

## 3. 方案一：机制变量 M 作为中介变量

### 3.1 适用情形

如果理论故事是：

**债务压力改变了某种机制变量的水平，而该机制变量进一步影响创新产出，进而解释了调节效应为何存在。**

那么 `M` 更接近“中介变量”。

这类设定对应的逻辑是：

`X × N -> M -> Y`

这属于“调节效应的中介传导”或“被中介的调节”。

### 3.2 模型设定

#### 第一步：机制方程

`M_it = a0 + a1 X_it + a2 N_it + a3 X_it * N_it + gamma Controls_it + FE + u_it`

这里重点看 `a3`：

- 若 `a3` 显著，说明债务压力对 `X -> Y` 的调节效应，会先体现在机制变量 `M` 上。

#### 第二步：结果方程

`Y_it = c0 + c1 X_it + c2 N_it + c3 X_it * N_it + c4 M_it + gamma Controls_it + FE + v_it`

这里重点看：

- `c4` 是否显著：机制变量 `M` 是否进一步影响创新产出
- `c3` 是否较基准模型中的 `beta3` 下降：说明原本的调节效应是否被 `M` 部分或全部解释

### 3.3 结果解释

- 若 `a3` 和 `c4` 都显著，且 `c3` 绝对值缩小，说明债务压力的调节效应部分通过 `M` 传导；
- 若 `a3` 和 `c4` 都显著，且 `c3` 不再显著，说明债务压力的调节效应主要通过 `M` 传导。

### 3.4 在本文中的典型理解

若将以下变量理解为“机制水平变量”，可优先使用这一方案：

- 早期投资金额、早期投资占比
- 社会资本撬动效率
- 企业融资约束指标

此时强调的是：

**债务压力会改变这些变量的水平，而这些变量的变化又进一步影响创新产出。**

---

## 4. 方案二：机制变量 M 作为调节变量

### 4.1 适用情形

如果理论故事是：

**债务压力通过改变某种机制变量，使该机制变量进一步改变 `X -> Y` 这条关系的强弱。**

那么 `M` 更接近“调节变量”。

这类设定对应的逻辑是：

`N -> M`

以及

`X × M -> Y`

也就是说，`M` 不是简单传导到 `Y` 的中间环节，而是在改变引导基金扶持创新的边际效果。

### 4.2 模型设定

#### 第一步：债务压力是否影响调节变量 M

`M_it = d0 + d1 X_it + d2 N_it + gamma Controls_it + FE + r_it`

也可根据理论需要扩展为：

`M_it = d0 + d1 X_it + d2 N_it + d3 X_it * N_it + gamma Controls_it + FE + r_it`

这里重点看：

- `d2` 是否显著：债务压力是否会改变调节变量 `M`
- 若采用扩展式，则进一步看 `d3` 是否显著

#### 第二步：将 M 作为调节变量引入结果方程

`Y_it = e0 + e1 X_it + e2 N_it + e3 X_it * N_it + e4 M_it + e5 X_it * M_it + gamma Controls_it + FE + w_it`

这里重点看：

- `e5` 是否显著：`M` 是否会调节 `X -> Y`
- 在加入 `X * M` 后，`e3` 是否较基准模型中的 `beta3` 下降：说明债务压力的调节效应是否部分通过 `M` 这种“调节路径”实现

### 4.3 结果解释

- 若 `d2` 显著且 `e5` 显著，说明债务压力确实会通过改变 `M`，进一步影响引导基金扶持创新的效果；
- 若在加入 `X * M` 后，`e3` 明显减弱，说明 `M` 是债务压力调节效应的重要承接变量；
- 若 `e5` 显著而 `e3` 不再显著，可进一步说明债务压力的调节效应主要通过 `M` 这种调节机制体现。

### 4.4 在本文中的典型理解

若将以下变量理解为“机制性调节变量”，可优先使用这一方案：

- 早期投资偏好
- 社会资本撬动效率
- 融资约束缓解能力

此时强调的是：

**这些变量本身会改变引导基金扶持创新的边际效果，而债务压力又会改变这些变量。**

---

## 5. 三重交互项的角色

如果进一步设定：

`Y_it = ... + X_it * N_it * M_it + ...`

则检验的是更强的命题：

**债务压力对 `X -> Y` 的调节强弱，是否还会随着 `M` 的不同而变化。**

这属于“调节的调节”或更强的扩展机制检验。

在本文中，三重交互项不宜作为主模型，而更适合作为：

- 扩展检验
- 补充稳健性分析

主文机制识别应优先在“方案一”和“方案二”之间明确选择。

---

## 6. 本文写作上的建议

### 6.1 若将机制变量写成中介变量

正文中可表述为：

**财政债务压力通过改变基金行为机制变量的水平，进而影响引导基金扶持创新效果。**

此时建议采用“方案一”的两步模型。

### 6.2 若将机制变量写成调节变量

正文中可表述为：

**财政债务压力通过改变基金早期投资偏好、社会资本撬动效率或融资约束缓解能力，进一步改变引导基金扶持创新的边际效果。**

此时建议采用“方案二”的模型，即在结果方程中显式加入 `X * M`。

### 6.3 当前论文更适合的理解

若以“早期投资偏好”为例，当前更适合将其理解为：

- 从理论机制上看，是债务压力调节效应的承接变量；
- 从计量角色上看，更接近调节变量，而不是普通中介变量。

因此，若主机制聚焦“早期投资偏好”，建议优先使用“方案二”。

若机制变量是更偏“水平变化”的指标，如融资约束均值、社会资本认缴水平等，则也可以用“方案一”补充检验。

---

## 7. 一句话总结

调节效应的传导机制有两种常见写法：

- 若 `M` 主要体现为某种“水平变化”，用 `X × N -> M -> Y` 的中介传导模型；
- 若 `M` 本身会改变 `X -> Y` 的强弱，用 `N -> M` 再结合 `X × M -> Y` 的调节机制模型。

二者都可以服务于本文，但必须先明确机制变量在理论上的角色，再决定相应的计量模型。
