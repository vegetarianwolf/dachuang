# 政府引导基金与地区创新——实证回归数据面板

## 项目概述

本项目基于"大致思路.md"中的研究设计，构建了一个地区创新的面板数据集。

**研究问题**：财政约束是否会通过改变地方政府的风险偏好（耐心资本角色），进而影响地区创新产出？

**时间范围**：2014-2024年  
**空间范围**：全国347个地级市  
**面板结构**：City-Year面板数据

---

## 数据文件

**主要输出**：cleaned_data/final_regression_panel_v2.csv
- 观测值：3,769条记录
- 变量数：28个
- 覆盖：347个城市 × 11年（2014-2024）

**处理脚本**：
- build_panel_optimized.py — 面板构建主程序（专利数据）
- process_fiscal_controls.py — 财政经济数据及控制变量处理

### ⏸️ 待解决的数据问题

**1. 政府债务数据覆盖率偏低（51%）**
- 仅262个城市有债务数据，部分年份缺失
- 考虑：debt_ratio可作为分组或子样本分析的变量，而非全样本核心变量
- 或寻找补充数据源

**2. 金融深度覆盖率低（38.1%）**
- 统计年鉴中贷款余额数据缺失严重
- 考虑：在稳健性检验中调整控制变量组合，或寻找替代指标

**3. 自治州/地区/盟缺乏经济数据（56个城市）**
- 这些非"市"建制的行政区划在CEIC中普遍缺失
- 考虑：在实证中使用有完整数据的子样本（~291个地级市），在论文中说明样本筛选标准

## 当前数据用途

### ✅ 可以做

1. **描述性分析**
