# Choice 创投事件原始导出

提取日期：2026年11月17日。来源为本机 Choice 金融终端“全球事件库 → 创投事件”，通过终端界面导出 Excel。

`raw/choice_events_*.xlsx` 为56个正式批次，查询区间连续覆盖2012-01-01至2024-12-31，共360,624条来源记录。地区、轮次、行业及其他条件全选，机构名称留空。记录包含港澳台地区及上市、收购、股权转让等交易类型。各批次日期、界面数量、行数、原始文件SHA-256见[逐批验收](../../实证结果/choice_download_20261117/batch_summary.csv)与[查询登记](../../实证结果/choice_download_20261117/ui_expected_counts.json)。

单次导出存在10,000条上限，正式查询均拆分至低于上限。`choice_probe_2020Q2.xlsx` 为验证上限的测试原件，独立保留，未进入正式数据。原始文件未作清洗或覆盖；页脚、空行和研究分类在派生表中处理。
