## 五、Stata vs Python 结果对比

### 5.1 基准回归 (核心控制, DV=ln(发明专利) ~ 财政缺口率)

| 指标 | Stata (本次) | Python v2 | Python v1 |
|:-----|:-----------:|:---------:|:---------:|
| β | 1.0758** | 1.0780** | 1.0435** |
| SE | 0.4580 | 0.4842 | 0.4821 |
| N | 2575 | 2575 | 2575 |
| R²(within) | 0.2484 | -0.0395 | -0.0410 |

> **R²(within) 差异说明**：Stata 的 `xtreg, fe` 报告的 R²(within) 包含了年份固定效应的解释力（通过 `i.year` 虚拟变量），而 Python `linearmodels.PanelOLS` 的 R²(within) 在 `time_effects=True` 时仅报告去除时间效应后的残差解释力，因此 Python 版本可能出现负值。**两者系数估计和标准误高度一致**，验证了回归的正确性。

### 5.2 中介效应 (fiscal_gap → M_deal → ln_inv, 核心控制)

| 检验步骤 | Stata | Python v2 | Python v1 |
|:---------|:-----:|:---------:|:---------:|
| 路径 a (X→M) | 0.0511 | 0.0554 | 2.0822 |
| 路径 b (M→Y\|X) | 0.0239 | 0.0238 | -0.0522 |

> Stata 和 Python v2 系数几乎完全一致（微小差异来源于浮点精度和缩尾处理的细微差别），相互验证了结果的可靠性。v1 的路径 a 系数差异较大，是因为 v1 使用当期中介变量（非滞后），且未限制子样本。

## 六、核心结论

1. **H1 (财政约束→创新)**：财政缺口率在加入核心控制变量后对发明专利有显著正向效应（β≈1.08, p≈0.03），但**方向与理论预期相反**。ln(债务率)在所有规格下不显著。

2. **H2 (中介效应)**：所有中介路径均不显著——X→M 路径的 p 值远大于 0.1，Sobel 检验 p≈0.97，**不支持中介效应假说**。

3. **跨工具一致性**：Stata 和 Python 的回归系数、标准误、显著性水平高度一致，验证了分析的可靠性。

4. **数据局限性**：中介变量覆盖率仅 21%（614/2909），严重限制了中介分析的统计检验力。
