# Choice 2012—2024 年下载最终验收

**56 个正式批次、360,624 条记录全部通过下载验收。**查询区间完整覆盖 2012-01-01 至 2024-12-31 的 4,749 个日历日，无缺口、无重叠。地区及其他条件均按 UI 全选记录，样本包含香港、澳门、台湾地区记录，轮次包含融资、上市、收购及股权转让等类型。

全量 `--final-check` 返回 0。56 批的行数与稳定 UI 计数一致，记录日期均在各自查询区间内；56 个原始文件的 SHA-256 与前次审计一致，读取期间均保持稳定。未发现无效日期或完全内容重复记录（比较时排除导出序号）。导出完整性以这些查询为单位，不代表数据库收录了全部市场事件。

2014Q1 的登记数已从 7,233 更正为 **3,476**。重新查询后，日期框与筛选芯片均为 2014-01-01 至 03-31；降序首日为 03-31、升序首日为 01-01，两次 UI 均显示 3,476。旧数来自尚未刷新完成的半年查询；此次修正依据 UI 回查，原始文件未改动。更正历史保留在 `ui_expected_counts.json`。

2020 年 4 月有 **26,188 条**，占 2020 年的 **51.1%**；最高单日为 04-08 的 **5,322 条**，04-10 为 2,626 条，与单日 UI 回查一致。四月无金额 25,698 条（98.1%），新闻标题及链接均缺失 25,762 条（98.4%）；房地产业 1,463 条，占 5.6%，记录集中现象涉及多个行业。该月轮次中股权投资 15,429 条、天使轮 8,208 条、Pre-A 轮 1,625 条。这些记录全部保留。源表没有录入时间，日期集中现象尚不能解释为集中补录；后续研究应另行核验事件日期与交易性质。

全样本金额缺失 269,327 条；源表明确数值为 0 的金额有 2 条，分别保留。公司名称无缺失，投资方按主审计口径缺失 **43,082 条**，包括空值 42,933 条、“未披露”148 条及“暂无”1 条。后续规范化另将“未透露”28 条列为缺失，合计 **43,110 条**；两者相差来自缺失标记定义，原始记录未改动。省级地区不能直接转换为企业所在城市，投资方名称也不能直接替代政府出资财政辖区。

`choice_probe_2020Q2.xlsx` 保留为导出上限测试原件，未进入上述 56 批、总记录数、日期覆盖或重复检查。它仅导出 10,000 条，不能用于补充正式样本；详见 [导出上限测试说明](导出上限测试说明.md)。原“进行中”快照已标注为历史记录，当前状态以本文及 `download_final_snapshot.json` 为准。
