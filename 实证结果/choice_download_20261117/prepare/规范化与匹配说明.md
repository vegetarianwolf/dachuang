# Choice 创投事件规范化与清科重合诊断

本次处理当前已完成的 56 个 Excel，保留 360,624 条来源记录和 232,965 个公司全名，已覆盖下载年份为 2012, 2013, 2014, 2015, 2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024。登记的全选查询区间连续覆盖2012-01-01—2024-12-31；各批次文件哈希、记录数、界面预期数与独立审计一致。

清科匹配底表包含 24,305 条真实来源记录、12,202 个公司全名；1 条错位重复表头已分流至源行诊断。公司全名经过 Unicode 统一和空白清理后，10,698 家与清科政府引导基金事件表重合，占本次 Choice 公司数 4.59%、清科公司数 87.67%。同公司同年候选 16,442 条，同公司同日候选 7,029 条；这两个层次用于核验同一融资事件。重合企业中 5,811 家在 Choice 中出现早于清科首个观察年份的事件记录，其中 3,315 家有更早的明确种子、天使、Pre-A、A、B 或 C 及以后轮次标签。两种历史口径分别保存，后续首投核验按选定的交易范围展开。

原表同时收录融资轮次、上市、上市后融资、收购与股权转让。独立轮次 flags 保留种子、天使、Pre-A、A、B、C 及以后等分组，并单列其他交易：上市 19,318 条，上市后融资 11,809 条，收购合并私有化 27,881 条，股权转让 9,131 条。后续 VC 研究需要先确定交易范围和各轮次的分母。

每条来源记录以文件哈希、工作表和 Excel 行号连接原表；供应商稳定事件ID、企业ID、信用代码、政府背景和投资方金额尚未出现在导出列。投资方原文完整保留，分词另存候选表，其中 5,921 个词元与清科基金全称精确重合。所有记录的政府背景维持 unknown；私人对照需补充事件发生时的基金及 LP 身份证据。

规范化文件保留原始金额、币种、投资方、地区、行业和新闻链接。金额未知留空，数值按来源单元格保存；未换汇。地区列保留原文，城市代码及历史有效期留空。融资时间保留原始精度和字段名，当前标签及相关新闻可能包含事后补录信息，时间有效性随数据字典核验。

金额数值可得 91,297 条、金额缺失 269,327 条；投资方名单缺失 43,110 条，其中下载验收口径下的缺项 43,082 条，另有原文“未透露” 28 条纳入规范化缺失统计，原文均保留。新闻链接缺失 300,051 条；数值金额对应币种缺失 0 条。下一步身份核验优先补企业统一标识及曾用名、投资基金法律实体与历史LP、事件发生时政府出资辖区；发生日和公告日分列、地区及行业的历史有效期随后与字段字典核对。

| 文件 | 用途 |
|---|---|
| choice_events_normalized.csv.gz | 全部来源记录及融资模板映射；压缩 CSV 可直接用 pandas 读取 |
| choice_round_flags.csv.gz / round_classification_rules.csv | 独立研究轮次 flags、完整原标签与规则 |
| choice_investor_tokens.csv.gz | 原投资方的分词候选；原名单仍在事件表 |
| government_event_candidates.csv.gz | 公司全名、同年、同日及基金全称的政府背景核验线索 |
| company_fullname_overlap.csv / overlap_by_year.csv | 公司重合、较早融资历史及逐年诊断 |
| template_field_assessment.csv | 标准融资字段的提供情况和实际含义 |
| qingke_source_row_index.csv | 清科原始行索引和匹配所需字段 |
| qingke_excluded_source_rows.csv | 清科错位重复表头的原逻辑行、源哈希和完整原记录 |
| source_notes.csv / independent_audit_comparison.csv | 原表来源备注与重复表头；按相同文件哈希核对独立审计有效行数 |
| prepare_summary.json | 输入输出哈希、快照范围、缺失和完整规则 |

原始 Excel 保持原样，全部融资来源记录保留。56 条页脚或重复表头另存来源备注，空白行跳过。重复内容增加标记，正式事件去重需要同时核验公司、日期、轮次、投资方和来源报道。脚本仅生成数据与诊断。

探查文件单独保留在 raw，其中 1 个非正式批次未进入规范化事件表；文件名、大小和用途记录于 prepare_summary.json 的 ignored_non_event_workbooks。
