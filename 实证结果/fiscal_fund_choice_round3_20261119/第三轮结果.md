# 财政约束、投前融资经历与后续融资

2026年11月19日 · 第三轮试验

**Choice 补足了企业融资历史，也给出了后续融资的负向线索。** 在原专利样本中，纳入投前融资历史几乎没有改变财政缺口率的系数。财政缺口与债务的交互项在后续融资模型中为负，估计幅度和精度对南京样本敏感。原假说的创新效果仍待有身份可核验的同期对照检验。

## 投前融资经历与企业创新

专利结果沿用第二轮 M1，衡量首次观察到地市级引导基金获投次年与前一年的发明专利申请对数差，即 `ln(1+申请量)` 之差。原样本159家，Choice公司全名匹配143家，其中37家在队列年之前已有明确创投轮次。两家首次匹配记录出现在队列年之后。在有专利记录的企业年份中保留发明申请的明确零值，缺行维持缺失。

两组主回归均控制队列年份以及来源城市上年GDP对数和第二产业占比，按来源城市聚类。财政缺口率按一般公共预算支出减收入后除以支出计算。专利变化使用OLS，二元融资结果使用线性概率模型。

| 规格 | 企业／来源城市 | 财政缺口率系数 | 95%置信区间 |
| --- | ---: | ---: | ---: |
| P0 复现原M1 | 159／41 | −0.306 | [−1.647, 1.035] |
| P1 Choice匹配样本 | 143／39 | −0.591 | [−2.251, 1.068] |
| P2 P1加入投前融资历史 | 143／39 | −0.584 | [−2.278, 1.110] |
| P3 同样本加入投前一年专利水平 | 143／39 | 0.163 | [−1.656, 1.983] |
| P4 P3加入投前融资历史 | 143／39 | 0.154 | [−1.697, 2.004] |
| P5 队列年及以前可匹配 | 141／39 | −0.583 | [−2.249, 1.083] |
| P6 P5加入投前融资历史 | 141／39 | −0.575 | [−2.273, 1.123] |

匹配样本的基准系数从 −0.591 到 −0.584，加入投前专利后的同样本系数从 0.163 到 0.154。可见的投前融资历史对这两个规格影响很小。财政缺口系数随投前专利水平控制而变号，区间均较宽，目前缺少稳定的负向创新证据。

## 后续融资与双重约束

在613家满足队列年、来源城市和财政数据要求的企业中，496家在队列年有Choice全名交易记录，来自83个基金来源城市。61家在此后两个日历年内出现明确创投轮次，占12.3%。较早轮次控制采用同长度的投前两个日历年。明确轮次涵盖种子、天使、Pre-A、A、B和C及以后轮次。后续融资为零表示Choice在该窗口未收录这类记录。

| 规格 | 企业／来源城市 | 目标项 | 系数 | 95%置信区间 |
| --- | ---: | --- | ---: | ---: |
| Q0 财政缺口基准 | 496／83 | 财政缺口 | −0.357 | [−0.756, 0.042] |
| Q1 加入投前融资经历 | 496／83 | 财政缺口 | −0.344 | [−0.734, 0.046] |
| Q2a 剔除月份记录后的共同样本，原记录口径 | 493／83 | 财政缺口 | −0.349 | [−0.739, 0.041] |
| Q2 同一批企业，剔除2020年4月记录 | 493／83 | 财政缺口 | −0.351 | [−0.738, 0.037] |
| Q3a 有债务数据的共同样本，沿用Q1 | 388／71 | 财政缺口 | −0.409 | [−0.849, 0.031] |
| Q3 加入债务主项与交互项 | 388／71 | 财政缺口×债务 | −0.082 | [−0.125, −0.038] |

Q1下，财政缺口率高10个百分点对应后续两年出现明确融资记录的概率低3.44个百分点，95%置信区间为[−7.34, 0.46]个百分点。Q2a与Q2有相同的61个后续融资正例，剔除月份记录改变了3家企业的投前融资标记。

Q3的债务比率为地方政府债券加城投债余额除以财政收入。两项财政变量均取自首次观察获投前一年。模型中，债务比率处于样本第25、第50和第75百分位时，财政缺口率高10个百分点分别对应融资记录概率低1.05、2.78和10.06个百分点。第75百分位的95%区间为[−14.86, −5.26]个百分点。线性模型中35家企业的拟合值超出0到1，本文用这些估计描述样本内的斜率。

### 交互项出现后追加的诊断

| 诊断 | 交互项估计 | 95%置信区间 |
| --- | ---: | ---: |
| 债务比率截至第95百分位，369家 | −0.092 | [−0.121, −0.062] |
| 加入财政缺口与债务比率的各自二次项 | −0.087 | [−0.137, −0.037] |
| 改用来源表债务／GDP口径，383家 | −0.715 | [−1.088, −0.342] |
| 剔除2020年4月记录，385家共同样本 | −0.079 | [−0.124, −0.034] |
| 剔除南京，374家 | −0.028 | [−0.078, 0.023] |

两种债务比率的计量尺度不同。换口径的共同样本中，原债务比率交互项为 −0.0815。采用相同协变量分别解释投前和投后两年的融资记录时，交互项分别为 0.0066 和 −0.0808。这是队列前后的条件关联对照，财政变量取值位于投前窗口内，不能当作外生冲击的平行趋势检验。

逐一剔除71个来源城市，估计均为负，范围为 −0.088 到 −0.028。南京占剔除其他控制项后交互项平方和的45.7%，14家企业中8家出现后续融资记录。去掉南京后置信区间跨零。负向方向值得在实际出资辖区和完整融资覆盖核验后复验，当前精度依赖该城市所提供的样本变异。

Guerini和Quas（2016，第13—15、20—22页）区分了首次私人融资、后续轮次与退出。Brander等（2015）按政府、私人和混合投资者比较融资及退出。本轮借用后续轮次的时间结构。Choice的轮次记录尚不能识别原基金续投或后续资金的政府及私人构成。财政端沿用基金注册城市代理，模型估计的是获投企业内的条件关系。

## 同期融资对照能做到哪一步

按融资年、省份、一级行业和标准化轮次，103家原专利样本企业可连接到具有相同专利窗口的同期企业，涉及1,544家不同候选。要求政府样本企业队列年的记录只落入一个匹配层时，剩94家。进一步核对初始基金全称，核心融资范围内同年且基金全称吻合者为11家，同日且基金全称吻合者为9家，同日、全称与轮次均吻合者为1家。企业同年存在一笔融资记录，距离确认它就是清科所记的政府基金进入事件还有一层核验。[同期融资风险集核验](同期融资风险集可行性.md)

下一轮取数可集中于候选的具体投资方及历史LP、政府基金对应事件的确切日期和轮次，以及未上市公司无专利行的覆盖含义。前两项决定处理事件与对照组，专利覆盖决定完整创新结果的分母。已有[第二轮方案](../fiscal_fund_design_round2_20261117/第二轮研究设计与结果.md)所列的政府基金与市场化VC比较可在这些字段补齐后开展。

[分析方案](分析方案.md)记录主规格，[估计结果](model_results.csv)、[全部系数](all_coefficients.csv)及[估计样本](estimation_membership.csv)可按规格和企业ID核对。[债务诊断](debt_diagnostics.csv)、[逐城结果](debt_leave_one_city.csv)和[边际关系](debt_marginal_effects.csv)与追加诊断日志对应。
