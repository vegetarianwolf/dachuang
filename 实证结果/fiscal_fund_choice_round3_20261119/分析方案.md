# Choice 融资历史如何改变财政约束的估计

2026年11月19日。以下规格在读取本轮回归结果前确定。研究沿用财政与债务约束削弱政府引导基金创新支持的假说，从专利估计的样本可比性和后续融资两个环节检验现有数据能支持的关系。

## 企业创新

承接第二轮M1的159家企业、原政府基金首次观察年份及来源城市。结果为投资次年与前一年发明专利申请的 `ln(1+件数)` 之差。控制来源城市上年GDP、第二产业占比和融资队列年，按来源城市聚类。

| 规格 | 样本 | 新增控制 |
| --- | --- | --- |
| P0 | 原M1 | 复现原式 |
| P1、P2 | 与Choice全名匹配的共同样本 | P1原式，P2加入投前年份已有明确创投轮次的指示变量 |
| P3、P4 | 同P1、P2 | 均加入投前一年专利水平，P4再加入融资历史 |
| P5、P6 | 首条匹配记录在政府队列年或之前的共同样本 | P5原式，P6加入融资历史 |

明确轮次沿用已验收的Choice标签。融资历史要求Choice年份严格小于队列年。同年融资不进入历史项。样本匹配按公司全称做Unicode规范化及空白清理。样本内的零表示2012年以来Choice未观察到该类较早记录。未匹配企业的融资历史留空。P5和P6检查全期名称匹配是否因投后才出现的记录而改变样本。

## 后续融资

从第二轮地市级政府基金企业中选取2016—2022年首次观察获投、初始来源城市唯一、有财政变量与控制变量且清科未观察到更早其他级别政府基金的企业。进一步要求Choice在队列年有同全名记录，将其作为公司在该年可被观察到的条件。队列年的Choice记录只用于锚定公司的可见性，政府投资时点沿用清科年份。选择这些年份保证Choice前后各两个完整日历年的查询均可用。

结果为队列年后两个日历年内是否出现明确创投轮次记录。基准控制与P0一致，并加入投前两年明确轮次指示变量。Q2a、Q2在相同企业上对照原口径与去除2020年4月记录的口径，重新计算历史与结果。Q3a、Q3在有滞后债务数据的共同样本上比较基准式和财政缺口率与债务比率的交互。Q3的债务比率以该共同样本均值为中心。完整结果保留方向、城市聚类置信区间和估计样本。

| 规格 | 样本及估计 |
| --- | --- |
| Q0 | 所有队列年Choice可见企业，原控制 |
| Q1 | Q0共同样本，加入投前两年明确轮次 |
| Q2a、Q2 | 去除2020年4月记录后仍有队列年Choice记录的共同样本，分别按全记录及剔除该月计算 |
| Q3a、Q3 | Q1中债务有效的共同样本，Q3加入债务主项和财政缺口与债务的交互 |

Choice创投轮次不含投资方的历史资本性质。后续融资结果衡量该源记录的融资，无法单独识别原政府基金的续投。财政压力对应原样本的基金注册城市代理。两项试验估计已观察到政府基金获投企业内的条件关联。政府与市场化VC的相对创新效应仍依赖同期可比企业、经核实的投资方性质和专利覆盖。
