# 社会资本撬动效率机制检验：中介式调节与调节式机制两种方案

## 任务与数据

- 回归日期：2026-05-18
- 数据集：`面板数据/地级市总面板_2015_2024_英文版.csv`
- 面板范围：2015-2024 年，277 个地级市，原始总样本 2770 个城市-年份观测。
- 主题：检验“债务压力/债务负担是否通过削弱社会资本撬动效率，进而解释政府引导基金促进创新的负向调节效应”。
- 核心解释变量：`fund_est_scale_cum`，基金累计设立规模；补充口径使用 `fund_est_scale_roll5`，基金近五年设立规模。
- 债务变量：`debt_pressure`、`debt_pressure_l1`、`debt_burden`、`debt_burden_l1` 及部分 1%/99% 缩尾口径。
- 机制变量：`soccap_leverage` 相关比例/效率口径，不对撬动效率取对数。
- 因变量：专利申请总量、实用新型申请量及其下一期/对数口径。
- 估计方法：地级市固定效应 + 年份固定效应，城市聚类稳健标准误。

## 样本与变量处理

本次只使用比例或效率类社会资本机制变量，不使用社会资本绝对金额、基金数量或匹配率指标作为核心机制变量。

处理包括：

- 对债务变量、社会资本撬动效率变量做 1%/99% 缩尾。
- 对 `soccap_leverage_govp5_w`，先剔除政府认缴额为正但处于 5% 分位以下、容易导致异常杠杆比的观测，再对撬动效率缩尾。
- 对 `D1_soccap_leverage_zero_w`，先将缺失的撬动效率补 0 并缩尾，再取一阶差分，表示社会资本撬动效率年度变化。
- 低金融发展样本定义为 `fin_dev` 低于样本中位数的城市-年份。
- 控制变量版本 `ctrl5` 包括：`ln_gdp`、`ln_fiscal_scitech`、`ln_pop`、`ln_secondary`、`ln_fdi`。

未进行的处理：

- 未对基金规模取对数。
- 未对社会资本撬动效率取对数。
- 未使用 `matched_share_total` 或 `matched_commit_amt` 作为机制变量。

## 两种模型方案

### 方案一：机制变量作为中介变量

第一步：

`M_it = a0 + a1 X_it + a2 N_it + a3 X_it * N_it + controls + city FE + year FE + e_it`

第二步：

`Y_it = c0 + c1 X_it + c2 N_it + c3 X_it * N_it + c4 M_it + controls + city FE + year FE + e_it`

判定标准：基准调节项 `X*N` 为负且显著；机制方程 `X*N -> M` 为负且显著；结果方程 `M -> Y` 为正且显著。

### 方案二：机制变量作为调节变量

第一步：

`M_it = d0 + d1 X_it + d2 N_it + controls + city FE + year FE + e_it`

第二步：

`Y_it = e0 + e1 X_it + e2 N_it + e3 X_it * N_it + e4 M_it + e5 X_it * M_it + controls + city FE + year FE + e_it`

补充扩展式将第一步改为：

`M_it = d0 + d1 X_it + d2 N_it + d3 X_it * N_it + controls + city FE + year FE + e_it`

判定标准：基准调节项 `X*N` 为负且显著；机制方程中债务变量或 `X*N` 对 `M` 为负且显著；结果方程中 `X*M` 为正且显著。

## 解释与写作建议

本轮检验支持将社会资本撬动效率写成“调节式机制变量”，而不是普通中介变量。更合适的机制表述是：

债务压力会削弱政府引导基金撬动社会资本的效率或效率改善；社会资本撬动效率越高，基金规模对创新产出的边际促进作用越强。因此，债务压力对“基金促进创新”的负向调节效应，部分体现为其压低了社会资本撬动效率这一承接变量。

写作时建议保持谨慎：

- 结果主要集中在低金融发展城市，说明机制具有情境依赖。
- 最强结果来自低金融、剔除 2020 年、滞后债务压力和撬动效率年度变化口径。
- 方案一没有找到完整链条，不建议作为正文主机制；可在附录或稳健性中说明曾检验但证据不足。
- 全链条 5% 结果存在，但主要属于扩展方案二；普通方案二多为 10% 水平，应作为机制证据而非过强因果断言。
