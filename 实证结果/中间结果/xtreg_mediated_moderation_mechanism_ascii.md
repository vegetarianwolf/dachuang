# 有中介的调节检验：债务压力作用下的基金累计规模、机制变量与创新产出

## 本次操作
- 使用数据：`staging_ascii/panel_2015_2024_regression_ascii_clean.csv`
- 回归方法：地级市固定效应 + 年份固定效应（`xtreg, fe`）
- 标准误：按城市聚类稳健标准误
- 时间范围：2015-2024
- 框架：检验 `fund_est_scale_cum x debt_pressure` 是否通过机制变量影响创新产出。

## 数据与样本
- 因变量：`pat_invent_apply`、`pat_utility_apply`、`pat_apply_total`
- 核心解释变量：`fund_est_scale_cum`
- 调节变量：`debt_pressure`、`debt_pressure_l1`
- 机制变量口径：早期投资、社会资本撷动、融资约束三类。

## 模型设定
1. 机制方程：`M = a0 + a1 fund_est_scale_cum + a2 debt_pressure + a3 fund_est_scale_cum x debt_pressure + FE + e`
2. 结果方程：`Y = b0 + b1 fund_est_scale_cum + b2 debt_pressure + b3 fund_est_scale_cum x debt_pressure + b4 M + FE + e`

- 社会资本和融资约束变量目前更多提供补充性证据。
