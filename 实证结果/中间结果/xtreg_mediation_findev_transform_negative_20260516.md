# 金融发展中介机制变量变换检验：负向相关结果筛选

日期：2026-05-16

## 1. 任务说明

用户指出 `xtreg_mechanism_finance_dualmodel_ascii.md` 第 4.1 节中，金融发展作为中介变量时，`fund_est_scale_cum × debt_pressure -> fin_dev_1` 有两条 5% 显著结果，但方向为正，与“债务压力削弱金融发展/金融环境”的理论预期相反。

本轮只重做机制方程第一步：

```text
M_it = a0 + a1 X_it + a2 D_it + a3 X_it * D_it + Controls_it + CityFE + YearFE + u_it
```

重点观察 `a3 = X × D -> M` 是否可通过学术规范内的变量处理变为负向显著。

## 2. 变量变换范围

- X：原始累计基金规模、`ln(1+累计基金规模)`、标准化、1%/99% 缩尾后标准化。
- D：债务压力、滞后债务压力、`ln(1+债务压力)`、`ln(1+滞后债务压力)`、缩尾后标准化。
- M 的同向变换：水平值、`ln(1+M)`、`asinh(M)`、缩尾、标准化。
- M 的变化量：一阶差分 `D.M` 和对数差分 `D.ln(1+M)`。
- M 的反向指标：`-M`、`-ln(1+M)`、`1/(1+M)`，只能解释为“金融发展不足/金融发展缺口”，不能说原金融发展水平本身负向。

面板设定为城市固定效应和年份固定效应，标准误按城市聚类；受控模型继续加入 `ln_gdp`、`ln_fiscal_scitech`、`ln_pop`、`ln_secondary`、`ln_fdi`。

## 3. 总体结果

全量机制方程估计 `2112` 条；其中负向且 10% 显著 `421` 条，负向且 5% 显著 `282` 条。

| 变量含义 | 估计条数 | 5%负向显著条数 |
| --- | ---: | ---: |
| same_direction | 1152 | 147 |
| change | 384 | 57 |
| reverse_coded | 384 | 72 |
| inverse | 192 | 6 |

关键判断：

- `fin_dev_1` 的同向水平变换没有得到负向显著；相反，水平、对数、asinh、缩尾、标准化等仍主要为正向显著。
- `fin_dev_1` 的变化量可以得到负向显著，尤其是 `D.ln(1+fin_dev_1)`。这表示债务压力和基金规模交互会压低金融发展增速，而不是压低金融发展水平。
- `fin_dev_2` 的同向变换可以得到负向显著，尤其在受控模型中，`ln_fund × ln(debt_pressure_l1) -> ln(1+fin_dev_2)` 或 `asinh(fin_dev_2)` 为负。
- 反向指标当然能让 `fin_dev_1` 变负，但应表述为金融发展不足/金融供给缺口上升，不宜把它包装成原始金融发展水平负向。
