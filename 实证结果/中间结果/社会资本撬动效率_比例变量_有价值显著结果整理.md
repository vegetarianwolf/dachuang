# 社会资本撬动效率机制：比例变量有价值显著结果整理

## 口径先说清楚

本轮只保留比例/效率变量，不使用绝对数量变量。

- `soccap_leverage`：社会资本撬动效率 = 社会资本认缴额 / 政府认缴额。最贴合题目。
- `soccap_share_total`：社会资本占总认缴比 = 社会资本认缴额 / 基金总认缴额。可解释为社会资本参与比例。
- `1-gov_share_total`：非政府出资占比。可作为社会资本化程度的替代口径。
- `matched_share_total`：已匹配认缴额占比。统计上很显著，但更像数据识别/覆盖比例，不建议作为主机制变量。

变量名中：`z_` 表示标准化，`_w` 表示 1%/99% 缩尾，`0` 表示缺失填 0，`L1_` 表示滞后一期。

## 最值得写进正文的结果

### 0. 机制方程本身的结果

机制方程检验的是：基金规模与债务压力的交互项是否会影响社会资本比例/撬动效率，即 `M = 基金规模 + 债务压力 + 基金规模×债务压力 + 固定效应`。

## 可以直接写进论文的表述

在仅使用比例变量的机制检验中，社会资本参与比例与非政府出资占比均表现出较稳定的显著结果。具体而言，社会资本占总认缴比提高后，政府引导基金累计规模对专利申请总量、发明专利申请和实用新型专利申请的边际影响均显著增强；采用非政府出资占比作为替代口径后，结果保持一致。这说明社会资本参与可能通过市场化筛选、资源协同和治理约束等渠道，提高政府引导基金支持创新的效率。

进一步地，社会资本撬动效率本身在对数化和缩尾处理后也呈现若干显著结果，但非缺失口径下方向不完全稳定。因此，本文可将“社会资本参与比例”作为主要机制证据，将“社会资本撬动效率”作为补充机制证据。债务压力三重交互项显著表明，在财政债务约束较强的情形下，社会资本比例会改变政府引导基金影响创新产出的路径，但其方向存在差异，需谨慎解释。
