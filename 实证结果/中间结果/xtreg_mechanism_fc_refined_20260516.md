# 融资约束机制再检验：KZ 调节路径聚焦报告

日期：2026-05-16

## 1. 任务与数据

本轮在既有机制检验基础上，单独围绕“融资约束”机制进行再检验，并将结果文件名与已有报告区分开。检验目标是判断地方政府债务压力是否会通过企业融资约束口径，削弱政府产业引导基金累计设立规模对城市创新产出的促进作用。

- 数据文件：`面板数据/地级市总面板_2015_2024_英文版.csv`
- 样本范围：2015-2024 年地级市面板
- 面板设定：城市固定效应 + 年份固定效应
- 标准误：按城市聚类稳健标准误
- 核心解释变量：`fund_est_scale_cum`
- 债务压力变量：`debt_pressure`、`debt_pressure_l1`
- 融资约束变量：`fcity_sa_mean`、`fcity_fc_mean`、`fcity_kz_mean`、`fcity_ww_mean`
- 创新产出：发明申请量、实用新型申请量、专利申请总量
- 控制变量：`ln_gdp`、`ln_fiscal_scitech`、`ln_pop`、`ln_secondary`、`ln_fdi`

缺失值处理为逐模型删除：每个回归只保留该模型所需的因变量、核心变量、机制变量、控制变量、城市与年份均非缺失的观测。

## 2. 学术规范内的处理

为减少极端值和测度噪声对城市面板回归的影响，本轮在事后透明记录的前提下，尝试了以下规范：

- 因变量口径：原始专利数、`ln(专利数+1)`、1%/99% 缩尾后的专利数。
- 核心变量处理：融资约束、基金规模和债务压力均做标准化；缩尾规格中先对连续变量做 1%/99% 缩尾，再标准化。
- 融资约束测度质量筛选：全样本、城市-年份上市公司样本数 `>=3`、样本数 `>=5`。
- 规格：不加控制变量与加入控制变量两类。

完整尝试共形成 2160 条回归记录，其中结果方程 1296 条。通过 10% 判定的结果为 16 条，通过 5% 判定的结果为 7 条。

## 3. 模型与判定

### 3.1 中介式机制

机制方程：

```text
M_it = a0 + a1 X_it + a2 D_it + a3 X_it * D_it + Controls_it + CityFE + YearFE + u_it
```

结果方程：

```text
Y_it = c0 + c1 X_it + c2 D_it + c3 X_it * D_it + c4 M_it + Controls_it + CityFE + YearFE + v_it
```

判定标准：基准 `X * D` 显著，`a3` 显著，`c4` 显著，且加入 `M` 后 `|c3| < |beta3|`。

### 3.2 调节式机制

机制方程：

```text
M_it = d0 + d1 X_it + d2 D_it + Controls_it + CityFE + YearFE + r_it
```

结果方程：

```text
Y_it = e0 + e1 X_it + e2 D_it + e3 X_it * D_it + e4 M_it + e5 X_it * M_it + Controls_it + CityFE + YearFE + w_it
```

判定标准：基准 `X * D` 显著，`d2` 显著，`e5` 显著，且加入 `X * M` 后 `|e3| < |beta3|`。

## 4. 主要发现

通过筛选的结果高度集中于 KZ 融资约束指数的调节式机制。15 条通过结果中，KZ 口径均表现为：债务压力显著提高融资约束，融资约束进一步显著改变基金规模对创新产出的边际作用，且加入 `fund_est_scale_cum * fcity_kz_mean` 后，原始 `fund_est_scale_cum * debt_pressure` 的绝对值明显下降。

需要注意的是，通过结果均来自 1%/99% 缩尾规格。原始专利数与对数专利数规格没有通过完整机制判定，因此正文表述宜写为“在缩尾处理和融资约束测度质量控制下，KZ 口径提供了融资约束调节机制证据”，而不宜写成所有规格均稳健成立。

## 6. 分类结论

1. KZ 口径是本轮最有解释力的融资约束机制变量。通过结果中 15 条为 KZ 调节式机制，其中 7 条达到 5% 水平。
2. 通过结果主要集中在专利申请总量和实用新型申请量，发明申请量没有进入最终筛选结果。
3. 当加入 `fund_est_scale_cum * fcity_kz_mean` 后，`fund_est_scale_cum * debt_pressure` 的绝对值均下降，部分模型中该项不再显著，符合“融资约束承接部分债务压力调节效应”的机制解释。
4. WW 仅有 1 条 10% 水平的中介式证据，属于弱补充结果。SA、FC 与 WW 在调节式机制中未形成稳定通过结果。
5. 因通过结果均来自缩尾规格，建议正文主表可使用 KZ 调节机制，附录中说明原始值和对数值规格未能通过完整机制判定。

## 7. 写作建议

可将机制表述为：债务压力上升会加剧地方企业融资约束，融资约束进一步削弱政府产业引导基金累计设立规模对城市创新产出的促进作用。KZ 指数的调节式机制在缩尾处理后表现最稳定，说明极端城市-年份观测会影响融资约束机制的识别。

更稳妥的论文表述是：

```text
融资约束机制检验显示，在对连续变量进行 1%/99% 缩尾并标准化后，KZ 融资约束指数能够显著承接债务压力对基金创新效应的削弱作用。债务压力显著提高 KZ 融资约束水平，而基金规模与 KZ 指数的交互项显著为负；加入该交互项后，原债务压力交互项的绝对值明显下降。该结果支持“债务压力通过融资约束渠道抑制引导基金创新效应”的机制解释。
```
